Two-Tier AWS Architecture — WordPress with Amazon RDS

## Project Overview

This project demonstrates the deployment of a WordPress application on Amazon EC2 with Amazon RDS MySQL as the backend database.

The architecture uses Amazon S3 for media storage and Amazon CloudFront for content delivery. AWS IAM and VPC networking were configured to support secure resource access.

## AWS Services Used

- Amazon EC2
- Amazon RDS (MySQL)
- Amazon S3
- Amazon CloudFront
- AWS IAM
- Amazon VPC
- Apache / NGINX

## Key Implementations

- Deployed WordPress on an Amazon EC2 instance.
- Configured Amazon RDS MySQL as the backend database.
- Integrated Amazon S3 for media storage.
- Configured Amazon CloudFront for content delivery.
- Configured IAM permissions for AWS resource access.
- Implemented VPC networking for application and database connectivity.

## Key Learnings

- WordPress deployment on AWS
- Application and database tier separation
- AWS networking and security
- Database connectivity
- S3 and CloudFront integration
